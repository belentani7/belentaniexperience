## Qué es

Belentani Experience es una interfaz editorial interactiva que convierte un portfolio en un sistema de señal: la apertura inicializa, el hero establece presencia, los expedientes muestran evidencia y el contacto abre un canal directo. La estética está aplicada al comportamiento; el sitio no expone sus reglas internas como contenido explicativo.

La dirección visual combina una máquina silenciosa, composición Gestalt, negro profundo, blanco frío, gris neutro, tipografía contenida y movimiento funcional. La experiencia evita promesas infladas, testimonios inventados y métricas no verificadas.

## Arquitectura

| Capa | Función |
| --- | --- |
| React + TypeScript | Portada, estados vivos, expedientes, filtros, terminal y navegación |
| CSS visual | Sistema negro/blanco/gris, apertura determinista, responsive y reduced-motion |
| Gestalt HTML | 20 escenas conectadas para explorar el protocolo visual sin depender de la portada |
| Vite | Desarrollo rápido, build de producción y code splitting |
| GitHub Actions | Checks automáticos de TypeScript y build |

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm check
pnpm build
```

El workflow de GitHub ejecuta los mismos checks en cada push y pull request. Las insignias del repositorio muestran únicamente estados que pueden verificarse automáticamente; el número de estrellas depende de adopción pública real y no se simula.

## Principios aplicados

La web prioriza claridad sobre ruido, evidencia sobre declaración, movimiento con función sobre decoración, y una narrativa acumulativa sobre una colección de pantallas aisladas. La apertura no usa imágenes ni textura: presenta negro profundo, línea fina, estado de señal y decodificación lenta antes de revelar el sistema.
