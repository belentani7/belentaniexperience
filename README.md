## Sitio

[belentanip-qaacxo29.manus.space](https://belentanip-qaacxo29.manus.space)

El proyecto presenta una experiencia editorial interactiva: una apertura de señal, un hero profesional, expedientes de trabajo, mapa de protocolos, perfil, sistema vivo y canal de contacto. La interfaz usa negro profundo, blanco frío, gris neutro, movimiento funcional y estados observables.

## Arquitectura

| Capa | Función |
|---|---|
| React + TypeScript | Portada, navegación, expedientes, filtros, estados vivos y terminal |
| CSS | Sistema visual, preloader, responsive, foco y reduced-motion |
| Gestalt HTML | Veinte escenas conectadas del protocolo visual |
| Vite | Desarrollo y build de producción |
| GitHub Actions | Verificación automática de TypeScript y build |

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Verificación

```bash
pnpm check
pnpm build
```
