# Investigación de referencia para la auditoría

## Fuentes consultadas

1. [Awwwards — Evaluation System](https://www.awwwards.com/about-evaluation/). Su sistema público pondera Design 40%, Usability 30%, Creativity 20% y Content 10%; también describe revisión por jurado y requisitos de publicación.
2. [CSS Design Awards — About](https://www.cssdesignawards.com/about). Destaca UI, UX e innovación, exige trabajo completo y original, información precisa, ausencia de errores y una ejecución suficientemente pulida.
3. [The FWA](https://thefwa.com/). La galería muestra experiencias inmersivas evaluadas por puntuación y selección editorial, con énfasis en narrativas digitales y ejecución visual.
4. [W3C — WCAG 2.2 Quick Reference](https://www.w3.org/WAI/WCAG22/quickref/). Base para percepción, operabilidad, comprensión y robustez.
5. [web.dev — Core Web Vitals](https://web.dev/explore/learn-core-web-vitals). Base para rendimiento de carga, interacción y estabilidad visual.
6. [MDN — prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion). Base para respetar preferencias de movimiento reducido.

## Síntesis operativa

La matriz no tratará los premios como autoridad absoluta. Se utilizarán como referencia de excelencia visual y narrativa, equilibrada con accesibilidad, rendimiento, claridad de contenido y coherencia del sistema. La identidad NOIACORE funciona como restricción superior: cualquier criterio que aumente el espectáculo pero rompa legibilidad, contraste, continuidad narrativa o rendimiento queda rechazado o se adapta.

La auditoría se organiza en ocho familias de 25 criterios: estrategia y narrativa; composición y jerarquía; tipografía y contenido; color y materiales; movimiento e interacción; accesibilidad y usabilidad; rendimiento y resiliencia; y arquitectura visual/sistema. Cada criterio se revisará con cuatro capas: visual, experiencia, técnica y coherencia sistémica. La decisión final se toma solo cuando las cuatro capas son compatibles.
